# Функции автопилотов Luna-16

Объекты `vessel`, `orbit`, `body`, `engine`, `autopilot`, `control` и `space_center` предоставляет API kRPC. Функции `run()` запускают этапы миссии; служебные функции вызываются изнутри скриптов.

## `ascent_autopilot.py`

| Функция | Назначение | Результат |
|---|---|---|
| `clamp(value, lower, upper)` | Ограничивает число диапазоном. | `float` |
| `lerp(x, x0, x1, y0, y1)` | Линейная интерполяция. | `float` |
| `commanded_pitch(altitude)` | Целевой тангаж по высотной программе. | градусы |
| `atmospheric_throttle(altitude, dynamic_pressure)` | Ограничение тяги около Max-Q. | 0-1 |
| `engines_with_name(vessel, name_fragment)` | Поиск двигателей по имени детали. | список |
| `resource_amount(parts, resource_name)` | Сумма ресурса в деталях. | `float` |
| `validate_vehicle(vessel)` | Проверка ТТУ, Mainsail и Poodle. | 3 списка |
| `jettison_fairing(vessel, state)` | Адресный сброс обтекателя. | `None` |
| `wait_for_active_vessel(conn, timeout)` | Ждёт загрузки активного объекта после разделения. | `vessel` |
| `activate_upper_stage(conn, vessel, state)` | Отделяет центральную ступень и запускает Poodle. | `vessel` |
| `stage_if_needed(conn, vessel, state, booster_parts)` | Отделяет выработанные ступени. | `(vessel, changed)` |
| `estimate_burn_time(vessel, delta_v)` | Оценка времени импульса. | секунды |
| `circularization_delta_v(vessel)` | Импульс циркуляризации. | м/с |
| `wait_for_circularization_thrust(...)` | Подтверждает тягу правильной ступени. | `None` |
| `execute_node(conn, vessel, node, state)` | Выполняет циркуляризацию. | `vessel` |
| `telemetry_path()` | Формирует имя CSV. | `Path` |
| `emergency_stop()` | Закрывает тягу и отключает автопилот. | `None` |
| `run()` | Весь этап выведения. | `None` |

## `mun_transfer_autopilot.py`

| Группа | Функции |
|---|---|
| Математика | `clamp`, `vector_subtract`, `vector_dot`, `vector_cross`, `vector_length`, `normalized` - числовые и векторные операции. |
| Двигатель | `engines_with_name`, `ensure_poodle`, `wait_for_thrust`, `estimate_burn_time` - поиск, проверка и расчёт Poodle. |
| Топливо | `available_fuel` даёт общий LF/Ox; `upper_stage_fuel` выделяет баки Poodle; `upper_stage_delta_v` оценивает их delta-v. |
| Энергия | `electric_charge`, `solar_flow`, `solar_exposure`, `sunlight_clearance`, `vessel_is_in_sunlight`, `wait_for_sunlight`, `orient_solar_panels`. |
| Связь | `deploy_long_range_antennas` раскрывает дальние антенны. |
| Манёвры | `wait_for_alignment` ждёт наведения; `execute_node` выполняет узел. |
| Окно к Муне | `orbital_longitude`, `initial_transfer_solution`, `closest_distance_for_node`, `plan_transfer_node`, `has_active_mun_encounter`. |
| Коррекции | `approach_altitude_after_correction`, `plan_kerbin_midcourse_correction`, `periapsis_after_radial_burn`, `plan_mun_periapsis_correction`. |
| Захват | `enter_mun_soi` контролирует перелёт; `plan_capture_node` строит тормозной узел. |
| Управление | `emergency_stop` аварийно останавливает; `run` ведёт весь этап. |

## `mun_landing_autopilot.py`

| Группа | Функции |
|---|---|
| Математика | `clamp`, `vector_subtract`, `vector_scale`, `vector_dot`, `vector_length`, `normalized`. |
| Конструкция | `electric_charge`, `engines_with_name`, `subtree_contains`, `find_poodle_separator`. |
| Место | `sun_elevation` рассчитывает освещение; `terrain_variation` измеряет рельеф; `find_landing_site` выбирает самый ровный освещённый кандидат. |
| Наведение | `point_opposite_velocity`, `wait_for_alignment`. |
| Poodle | `brake_with_poodle`, `wait_for_lander`, `reduce_separator_force`, `wait_for_poodle_clearance`, `safely_separate_poodle`. |
| Посадка | `target_descent_speed` задаёт профиль; `activate_landing_engines` запускает 8 двигателей; `deploy_landing_legs` выпускает опоры. |
| Управление | `emergency_stop`, `run`. |

## `mun_return_autopilot.py`

| Группа | Функции |
|---|---|
| Математика | `clamp`, `lerp`, `vector_scale`, `vector_dot`, `vector_length`, `normalized`. |
| Конструкция | `engines_with_name`, `return_engines`, `descendants`, `has_part`, `find_ascent_separator`, `find_capsule_separator`, `validate_landed_vehicle`. |
| Запас | `electric_charge`, `weighted_engine_performance`, `available_delta_v`, `predicted_ascent_stage_budget`, `estimate_burn_time`. |
| Взлёт | `wait_for_return_stage` выбирает зонд; `activate_engines` запускает двигатели; `commanded_pitch` задаёт тангаж; `launch_from_mun` достигает апоцентра. |
| Орбита | `circularization_delta_v`, `execute_node`, `circularize_mun_orbit`. |
| Возврат | `patched_orbit_for_body`, `kerbin_periapsis_for_node`, `plan_kerbin_transfer`, `wait_for_kerbin_soi`. |
| Коррекция | `kerbin_periapsis_after_correction`, `plan_kerbin_correction`. |
| Капсула | `altitude_at_ut`, `inbound_ut_for_altitude`, `point_retrograde`, `separate_capsule`, `wait_for_capsule`. |
| Парашют | `arm_parachute` заранее взводит; `deploy_parachute` раскрывает; `perform_reentry` управляет активным или пассивным входом. |
| Возобновление | `can_resume_kerbin_reentry` распознаёт сохранение; `resume_kerbin_reentry` продолжает вход. |
| Управление | `wait_for_alignment`, `emergency_stop`, `run`. |

## Ошибки

При нарушении условий безопасности функции поднимают `RuntimeError`. Обработчик в конце каждого автопилота вызывает `emergency_stop()` и повторно поднимает исходную ошибку для диагностики.
