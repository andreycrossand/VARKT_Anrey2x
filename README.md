# Luna-16 KSP

Комплект автопилотов kRPC для полной миссии: старт с Кербина, перелёт к Муне, мягкая посадка, взлёт с Муны и возвращение капсулы на Кербин.

## Финальная сборка

Используйте `craft/Luna16_Mun_FINAL.craft`.

В каталоге `craft` также оставлены две предыдущие сборки для сравнения:

- `Luna16_Mun_Carrier_V3_FIXED_1.craft`;
- `Luna16_Mun_Carrier_V3_FIXED_2.craft`.

## Требования

- Kerbal Space Program с модом kRPC;
- запущенный сервер kRPC;
- Python и пакет `krpc`;
- активный аппарат должен соответствовать текущему этапу миссии;
- перед каждым этапом проверьте заряд, топливо и активный корабль.

Проверка связи:

```bash
./.venv/bin/python connection_test.py
```

## Порядок миссии

### 1. Выведение на орбиту Кербина

```bash
./.venv/bin/python ascent_autopilot.py
```

Условия: ракета стоит на стартовом столе, тяга закрыта. Подтверждение: `ПУСК`.

Автопилот выполняет гравитационный разворот, отделяет ТТУ, безопасно переходит на Poodle и формирует орбиту около 100 км. Телеметрия записывается в `telemetry`.

### 2. Перелёт к Муне

```bash
./.venv/bin/python mun_transfer_autopilot.py
```

Условия: стабильная орбита Кербина с перицентром выше 75 км. Подтверждение: `ЛУНА`.

Скрипт выбирает окно, выполняет разгон, корректирует перицентр и тормозит до орбиты Муны около 50 км. При повторном запуске может продолжить уже сформированную встречу.

### 3. Посадка на Муну

```bash
./.venv/bin/python mun_landing_autopilot.py
```

Условия: связанная орбита Муны в диапазоне 15-120 км. Подтверждение: `ПОСАДКА`.

Автопилот ищет освещённую площадку с минимальным перепадом рельефа, использует остаток Poodle, безопасно отделяет его ступень и садится на восьми боковых двигателях. Если идеально ровной площадки нет, выбирается самая ровная из всех освещённых на доступной трассе.

### 4. Возвращение на Кербин

```bash
./.venv/bin/python mun_return_autopilot.py
```

Условия: аппарат неподвижно стоит на Муне. Подтверждение: `ДОМОЙ`.

Скрипт отделяет взлётный зонд, выводит его на орбиту Муны, формирует возвратную траекторию, отделяет капсулу и управляет входом в атмосферу. Перед входом создаётся отдельное сохранение `Luna16_before_reentry`. При нулевом заряде скрипт переходит на пассивный вход и заранее взводит парашют.

## Сохранения и остановка

- перед критическими этапами создаются `quicksave`;
- перед входом в атмосферу создаётся `Luna16_before_reentry`;
- `mun_transfer_autopilot.py` может подхватить уже сформированную встречу с Муной;
- `mun_return_autopilot.py` распознаёт аппарат у Кербина и продолжает вход;
- `Ctrl+C` закрывает тягу и отключает автопилот.

## Файлы

- `ascent_autopilot.py` - выведение на орбиту Кербина;
- `mun_transfer_autopilot.py` - перелёт и захват Муны;
- `mun_landing_autopilot.py` - выбор площадки и посадка;
- `mun_return_autopilot.py` - полное возвращение;
- `connection_test.py` - проверка kRPC;
- `docs/Функции_автопилотов.md` - справочник по функциям;
- `docs/Инструкция_по_автопилоту.pdf` - PDF-инструкция.

## Структура проекта

- `craft/` - финальная ракета и две предыдущие проверенные сборки;
- `docs/` - инструкция, технический отчёт и справочник функций;
- `telemetry/` - три последние записи выведения;
- `research/` - конспекты, схемы и материалы физической модели;
- `.venv/` - локальное окружение Python (в Git не добавляется);
- `.idea/` - локальные настройки PyCharm (в Git не добавляются).
